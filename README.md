# Calculator

A simple browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division, and modulo
- Number input with decimal support
- Clear (`AC`) and delete (`DEL`) actions
- Instant calculation with the equals (`=`) button
- Responsive, lightweight front-end design

## Project structure

- `index.html` – Calculator layout and button elements
- `style.css` – Styling and responsive appearance
- `script.js` – Calculator logic and event handling

## How to run

You can run the app directly in a browser without any build step:

1. Open `index.html` in a modern web browser, or
2. Serve the project locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Notes

This is a front-end-only project, so no backend or package installation is required.
